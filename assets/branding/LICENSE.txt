Rasterized outputs
------------------
- assets/branding/launcher/*.png  - Android launcher, adaptive, themed, splash
- store/play/*.png                - Play listing icon, feature graphic, web icons

The PNGs are generated. Do not hand-edit them; change the SVG and re-run:

    godot --headless --path . -s tools/branding/generate_store_assets.gd

Note on the wordmark: Godot's SVG rasteriser ignores <text> elements, so the
"MIXING FLAVORS" wordmark and the "DEDUCE - CARVE - REVEAL" tagline in
feature_graphic.svg are authored as stroked vector paths on an explicit glyph
grid rather than set as text.
